## 学習内容

### 1. range関数を使った繰り返し処理

`range()` 関数を使って、0から4までの数を出力する方法を観測した。

```python
for i in range(4):
    print(i + 1)
```

#### 実行結果

```
1
2
3
4
```

#### 学んだこと

- `range(4)` は 0～3 の値を順番に生成する。
- `i + 1` とすることで、1～4を表示できる。
- `for` 文と組み合わせることで繰り返し処理を実現できる。

---

### 2. len関数による要素数の取得

`len()` 関数を用いて、基盤コースの数を調べるプログラムを作成した。

```python
classes = ['M', 'D', 'E', 'I']

print('基盤コースの数: ' + str(len(classes)))
```

#### 実行結果

```
基盤コースの数: 4
```

#### 学んだこと

- `len()` はリストの要素数を取得する関数である。
- `classes` には4つの要素が含まれている。
- 数値を文字列と連結するために `str()` を使用した。

---

### 3. range関数とlen関数を利用した番号付き表示

`range()` と `len()` を組み合わせて、番号と基盤コース名を表示するプログラムを作成した。

```python
classes = ['M', 'D', 'E', 'I']

for i in range(len(classes)):
    print(i + 1, classes[i])
```

#### 実行結果

```
1 M
2 D
3 E
4 I
```

#### 学んだこと

- `len(classes)` によってリストの要素数を取得できる。
- `range(len(classes))` によって 0～3 の添字を順番に取得できる。
- `classes[i]` とすることで、各要素にアクセスできる。
- `i + 1` を用いることで、1から始まる番号を表示できる。
